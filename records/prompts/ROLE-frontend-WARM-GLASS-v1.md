# ROLE-frontend-WARM-GLASS-v1

操作者：前端 AI agent；决策来源：用户 U017/U018 UI 要求及总协调分派。不是学生亲自编写代码或独立测试。

## 实际执行的工作提示

先读取项目协作规则、当前 Vue/Element Plus 组件和本岗交接；使用固定提交的 OpenDesign 官方本地技能和模板做设计，不冒称桌面应用或 MCP 已运行。用户要米色浅咖啡色、苹果液态玻璃效果和更多圆角；先在 docs/ui/warm-glass 写明确 token、组件与回退设计，再做登录/工作台/任务详情可点击合成原型。用真实 Chrome 看 1440 与 390px，保留开发截图和内部五维自评，先形成设计 checkpoint，之后才映射到现有前端。

导入时保持所有请求、接口、状态、权限、错误、幂等与通知双计数行为；不添无 API 的搜索/图表，不更改独立用例或源码统计口径。生产玻璃限定在导航和浮层，正文足够实底，采用 CSS backdrop blur、薄边、高光、柔阴影和圆角层级，保留减少透明度/动效和无支持回退。仅进行适当现有前端测试、typecheck/build 和实际浏览器视检。所有测试脚本在 tmp/ 且使用 root 分配的918号；各 Vite 使用独立 cacheDir，禁止碰独立测试端口、数据库和未发布证据。分阶段 commit，更新本岗日志/模块报告/交接及 GitHub 协作。

## 改进理由

把宽泛审美要求转成颜色、材质、组件、响应式和验证边界；先设计后实现有实际提交顺序；明确 OpenDesign 本地文件使用与完整桌面/MCP 调用之间的区别，避免工具能力和验收事实被夸大。
