## 5. 正确性与归因

源码 `contract.ts:5` 的 Json 联合包含 boolean、string，`initial():15-25` 对 string/未知 schema 本来返回 `''`，boolean 返回 false、明确 const 原样。公开编译原件 before 是 `type: [null, Boolean, Number, String, Array, Object]`，Boolean 在 String 前。组件新增断言修前实际收到 value=true；纯 initial 断言却通过，和这个边界转换的根因吻合。故不能把问题归因于初值函数、米咖 CSS 或API返回。

修复后的显式 `type:null as unknown as PropType<Json>` 在运行时是 null，避免 Boolean casting；TypeScript 类型和 required 保留。真实布尔 checkbox true/false，以及数字、日期、枚举、数组更新由新增与既有受影响组覆盖；schema及服务端校验仍是业务约束来源。

真实浏览器最终 DOM 记录在1440和390均 title/description/delay_contingency为空，提交缺字段后 requiredErrors=true，业务写请求为0。实际查看四张原图，桌面三字段均为空，手机可见字段为空、错误和关闭可读；手机视口外的字段值以DOM记录为据。
