# 合成数据声明

seed_demo生成的项目、任务、依赖、八段评审、十项检查、预案及决定均为程序合成夹具。
合成账户不是实际参加者，批准、通过和交付状态只供页面演示、查询与负载验证；不能作为真人评审、人工改码、真实交付、产品测试通过或独立验收的证据。

评审模板读取后端发布的真实版本化配置并保存原始字节SHA256。artifact_revision引用本项目实际持久门面阶段提交a83fe2806a68ec8dc938748d623bf28c9a16b293，仅表示夹具使用的对象基线，不宣称该提交经过这些虚构评审。
数据库口令、演示用户口令及原始hash不出现在返回值或执行日志；新合成用户获得随机不可复原的口令hash。需要登录演示时，应由授权CLI为预先创建的manager账户初始化口令，再按manager_username复用；另两个合成账户不能直接登录。

数据一次事务写入，仅接受空项目集；已成功的数据用合成审计标记重复识别，不删除或覆盖现有项目。依赖只指向同项目序号更小且交付状态的任务，保证无环。预案作者与预案评审者、代码评审者与任务负责人相互独立。

生产入口seed_demo(factory, projects=40, tasks=6000, dependencies=9000, records=15000, seed=44, anchor_at=None, template_path=None, rules_path=None, batch_size=250)，无明文密码参数；生成账户使用随机秘密的合法Argon2id hash，复用已有账户时不修改hash。seed/version/anchor和真实模板、规则原字节hash组成manifest_sha256，这是生成描述摘要，不冒称整库内容或随机口令hash可重现。

默认七态：已交付2400；待受理、开发、阻塞、待评审、待上线、已回滚各600。评审11400+决定3600=15000，预案另3600。当前delivery_cycle/schedule_version均1，review_cycle可递增；不声称覆盖所有历史周期组合或极端业务分布。
