两台均选Ubuntu24.04 LTS x86_64官方公共镜像，同地域、同可用区、同VPC及交换机；[Docker官方支持Ubuntu24.04](https://docs.docker.com/engine/install/ubuntu/)。[阿里云购买说明](https://help.aliyun.com/zh/ecs/user-guide/create-an-instance-by-using-the-wizard)说明同可用区内实例延迟更小；压测使用私网IP，[同地域内网流量免费](https://help.aliyun.com/zh/ecs/user-guide/network-bandwidth)，内网带宽取决于实例规格，不要把公网带宽上限误当压测能力。

公网只用于管理、依赖获取和必要展示，先用按流量的小带宽配置，不购买大公网带宽。SSH限制为本人管理IP，数据库/队列不开放公网；应用管理沿原SSH隧道方式。正式内网测试入口由部署岗后续按发压机来源单独配置，不能直接把现有loopback8080当跨机已连通。中国内地的镜像/依赖获取可用性须在计划中核验，不能承诺购买后两小时必定完成三组测试。
