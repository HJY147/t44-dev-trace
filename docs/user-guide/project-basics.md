## 这些部分分别做什么

| 部分 | 简明解释 | 本题例子 |
| --- | --- | --- |
| 前端 | 浏览器中看到和点击的界面 | 查看任务、填写阻塞原因、发起评审 |
| 后端 | 收到请求后检查身份、权限与业务规则 | 拒绝“开发中”直接跳到“已交付” |
| 数据库 | 持久保存任务及其来龙去脉 | 保存状态、依赖、评审和拍板记录 |
| 消息队列 | 将通知任务交给消费者处理 | 发送升级通知并防止重复通知 |
| 定时调度 | 按设定时间自动执行工作 | 定期找出临期和超期任务 |
| 部署 | 把这些部分放到运行环境并管理启动 | 配置环境、启动服务、备份和恢复 |

接口契约是前后端共同遵守的说明：请求要传什么、会收到什么、出错怎样表示。状态机是允许和拒绝任务状态变化的规则。幂等指同一件事重复提交或重复扫描，不会重复产生业务结果。这些都需要实现和验证，解释概念本身不算测试通过。
