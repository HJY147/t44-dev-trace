# 模块报告模板

每个岗位以真实证据填写，不适用或尚未开始的项目明确说明。初始化阶段不得写已实现、联调通过或验收通过。

## 任务与依据

岗位、阶段、负责的 FR/AC 或用户要求、需求来源、版本。

## 产物与当前状态

列出实际文件、代码入口、配置、报告和尚未实现的内容。

## 模块输入输出及对接

上游、下游、接口/事件/字段草案或冻结版本、错误条件、已确认与待确认的事项。

## 设计与取舍

采用的方案、候选方案、选择理由、人机决策边界。

## 执行与验证

实际命令、环境、结果、证据路径。分别写模块自测、集成验证与独立验收，不能相互替代。

## 过程记录及提示词

关联日志、提示词 ID、实际修改者和决策者。未发生的过程不得补造。

## 问题与交接

未解决事项、请求其他岗位提供的内容、后续步骤。
