## 实际有意义的prompt改进与产物映射

1. **将“继续解决”变成资源和证据边界。** 858原失败保留后，857新freeze/准入把FD生效阶段、parent包络、孩子before/after读回、无重试/无SUT/无600s写清。产物是公开metadata/准入与有限stub摘要；不是把失败更名成功或本岗读取私密方法。
2. **把人的选择缩到可审失败槽。** 后端实际prompt `agents/backend/release-error-priority/actual-prompt.md`要求“本阶段只RFC，不改任何冻结文件/应用/测试”，并要求“别为了一个提示顺序改全架构”。产物是最小scope/RFC/守卫表，人的D008与AI设计清楚分开。
3. **根据真实源复核细化重放承诺。** reviewer原8c意见→R2续派与文档差量，把条件4xx COMPLETE、动态成功Meta、错误无outerMeta、未知commit逐项写准。产物是R2文档限定准入与公开全文GET，不能美化成应用修复或所有响应字节不变。
