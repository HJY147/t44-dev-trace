留痕 · 米咖玻璃原型内部自评

2026-10-23 · 前端开发岗，参考 OpenDesign critique 五维框架。作者自评，非独立审核或自动评分。已逐张查看 1440/390 的工作台、登录、详情及表单错误共 8 张截图；浏览器完成交互，无页面错误、无页面横向溢出。

一致性 · 7 / 10

prototype.html 的 .sidebar、.topbar、.metric、.panel 与登录卡共享米咖 token 和圆角层级。没有蓝色遗留。玻璃为静态淡高光，正文近实底；满足用户方向，但通透感较克制，仍需在实际 Element Plus 抽屉中复核。

保留：品牌浅咖、奶油底、深咖正文统一。

视觉层级 · 7 / 10

.heading 的 30px 标题、四个 .metric 数字与 .record-head 的任务标题形成清晰层级。手机指标 2×2，内容连续可读。原型展示的 3 条任务不能说明真实项目多条记录的密度，导入后需使用服务端任务检验。

保留：操作按钮在列表前，不添无 API 趋势图。

细节 · 6 / 10

桌面侧栏与顶栏外边距一致，390px 无页面横向溢出。手机原型工具栏换成两行，而原型浮层 top 初始固定 49px，会盖住工具栏底部；这是预览壳边界，生产不应复制。表单必填星号独占一行也较松散，实际沿用原组件同行标签。

修正：生产浮层由 Element Plus 管理，不复制原型预览壳。

功能 · 6 / 10

918 浏览器脚本已实际点击登录示意、任务详情、Esc 关闭、状态筛选和空表单错误。原型明确不连服务、不执行业务；尚不能代表真实登录、通知统计、403/409 或失效重试。原型未实现完整焦点陷阱，生产保留 Element Plus 原焦点管理。

修正：导入后核验真实登录/列表/详情/本地表单错误，保留原业务测试。

创新 · 5 / 10

暖米咖与漂浮玻璃让原有冷色工作台有辨识度，登录的简洁流程卡能延续“留痕”语义。但导航、卡片和抽屉仍为常用工作台结构；没有为创新而增加装饰性交互，也不应把材质样式写作算法创新。

快速改进：把实际 favicon 和错误/空态也同步米咖。

保留

  • 浅咖行动色、深色正文和接近实底的内容层。
  • 24–30px 容器与 pill 按钮的层级，桌面/手机一致。
  • 示意标签与已有 API 功能边界。

接入时处理

  • P1：实际对话框/详情使用 Element Plus 管理位置和焦点。
  • P1：真实通知两个计数、业务表单及错误状态不被视觉重构覆盖。
  • P1：玻璃不支持、减少透明度和减少动效回退。

快速改进

  • favicon 改暖咖色。
  • 状态标签保留文字且按状态补充红黄绿。
  • 在真实数据的手机长标题下复查按钮换行。
