# 留痕 · 奶油咖啡玻璃界面

本稿由用户的“米色浅咖啡色、苹果的液态玻璃效果、多设计圆角”及“先用 OpenDesign 设计好 UI 再导入”直接驱动。使用 OpenDesign 官方本地 agent 技能与设计系统文件，不代表启动了 OpenDesign 桌面应用、MCP 或外部生成模型。来源、版本、文件摘要和许可见 `sources.json` 与 `NOTICE.md`。

## 视觉方向

为反复查看任务、依据和审计记录的团队设计一个安静、温暖的工作空间。奶油色承托内容，浅咖啡色标记行动与选择；半透明导航和浮层带来玻璃的薄边、高光和层次。正文与表单保持足够不透明，长时间阅读优先。

结构化 brief：`palette=earth_tones`、`typography=system_ui`、`display=same_as_body`、`layout=two_column`、`mood=professional_minimal`、`density=balanced`；用户指定的浅咖啡 accent、圆角和玻璃材质覆盖 design-brief 的闭集色值、warm-editorial 的禁止玻璃规则及 frontend-design 的通用保守建议。未指定的字体、密度与动效由前端岗选择；不是新的人工业务决策。

## 字体与节奏

本机系统 UI 字体 + PingFang SC / Microsoft YaHei；不下载字体。中文标题 28–32px/1.3、正文 14px/1.8、标签 13px/1.6、元数据 12px/1.7；大数值 34px 使用等宽数字。间距以 4px 为基准，常用 8、12、16、20、24、32px。

## 组件

- 容器 26–30px、内部卡片 20–22px、输入框 14px、按钮和分段选择 999px；保留圆角层级。
- 侧栏和顶栏为漂浮玻璃：1px 浅高光边、低透明咖啡阴影、`backdrop-filter: blur(22px) saturate(125%)`。不使用持续动画、SVG 滤镜或跟随指针效果。
- 内容面板与表单为接近实底的 paper；抽屉和对话框具备玻璃外壳，正文不透出背景文字。
- 按钮至少 38px，手机主要操作至少 42px。disabled 仍可辨认；hover 改颜色与细边，不移动布局。
- 提示、空态、加载、403/409/422/503 错误保留原有文字与操作。通知“未读”和“未处理”分别展示，绝不合并统计。
- 登录加入品牌说明区与装饰性的流程卡；实际登录字段、提交和错误处理保持原样。手机隐藏装饰，集中填写。

## 布局

桌面 16px 外边距、244px 漂浮侧栏；主区与顶栏对齐，工作区最大 1640px。四个真实概览指标后接任务列表，保持现有流程，不新增无 API 支撑的搜索、趋势图或预言性进度。

≤760px 隐藏桌面侧栏，使用原抽屉导航；顶栏紧凑、指标 2×2、表单单列、详情抽屉满宽。390px 不横向滚动。任务、成员和通知完整记录允许纵向展开。

## 层次与回退

玻璃仅用于导航和浮层；卡片采用静态柔阴影 `0 10px 36px rgb(94 68 44 / 6%)`。背景为静态大面积暖色渐变，没有运动装饰。`@supports` 不支持 backdrop 时改不透明 paper；`prefers-reduced-transparency` 同样回退；`prefers-reduced-motion` 禁用过渡；forced-colors 保留系统颜色。

## 交互与可访问性

保留语义 label、skip-link、焦点、Esc 关闭和原对话框焦点管理。任务状态有文字，错误有 role=alert，通知有 role=status。表单深色正文、浅实底、可见边框；不靠颜色区分是否允许操作。

## 实施边界

`prototype.html` 是可点击、多场景的合成示意，不连接业务服务，不具有真实登录或状态推进。设计 checkpoint 提交后，才把视觉结构映射到现有 Vue/Element Plus 组件。原型 CSS 不作为生产业务模块；实际产品样式仍在 `frontend/src/styles.css`，无业务搬迁来改变源码统计。

验证包含原型和实际产品的 1440px/390px 浏览器视检、现有测试、typecheck/build。开发岗截图与检查不作为独立验收或学生手工测试。
