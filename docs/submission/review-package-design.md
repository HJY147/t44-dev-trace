# 可复核源码包设计

此包用于本地审阅与离线保存，不表示最终验收通过或课程最终提交。作者为协调AI。当前仍需独立完整验收、正式性能、代码规模出口、学生亲写研究正文和实际人工留痕。

## 输入和范围

输入为一个明确40位Git提交。只从该提交中选择项目公开源码/构建锁文件/冻结规格/技术文档/公开证据和开发者测试，按显式根目录白名单打包；不递归读取本机工作区。先按路径元数据筛选，再读取选中的Git blob，不读取任何未发表的独立用例或结果。

不收集 tmp/independent、.agent-worktrees、.submission-private、环境文件、私钥、账号、依赖安装目录、构建缓存或原始教师Word/音频。公开仓库中已有的明确发表独立报告可保留。私密封面与四技术Word不放开源源码包；随后可在本地另组课程审阅材料，但不能误传到公开仓库。

## 输出和核验

输出仅在本项目忽略的 .submission-private/review-packages 下，目录0700、ZIP和清单0600、拒绝覆盖已有输出、符号链接及路径逃逸。源码内容保持Git原字节；每个归档文件记录Git对象ID、SHA256、大小和可执行标志。包内说明明确review-only、原始提交和未达标出口，以逐项现有报告为准，不复制AI编造的整体通过状态。

封包后重新打开ZIP，核对成员集合、逐项解压字节SHA与大小、无绝对路径/路径穿越/链接/重复成员，以及全部期望范围。核验失败不宣布完成；半成品仅删除本次自有新文件。清单记录ZIP SHA256，便于之后重做源比对。该核验是归档完整性检查，不是产品测试。

## 重现

实施脚本将提供 --commit 精确提交参数，默认当前HEAD但会解析并记录最终40位；输出不会上传，不替换源代码、报告、测试结果或任何已有包。实际执行后记录准确来源/排除范围/文件数/归档hash；最终稳定来源出现时可另建新名字，不覆盖历史包。
