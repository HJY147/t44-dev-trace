# Backend structural reduction design, 2026-10-25

Operator: backend AI. Base integration e45a2b980c6ba8c61761f897414d54a10000409d, product 935ab5b93bea788672c2b4a088c79cfeed848954. Scope is domain, services, api.py and contracts/__init__.py. No persistence change, frozen JSON change, runtime data, independent test material or test deletion is permitted.

The first extraction makes semantic enums own their stable numeric storage code while retaining their existing string .value and member identities/names. The service State/Action compatibility classes and conversion maps are derived from those codes. The accept-review/approve-review naming difference remains an explicit adapter alias. Error-code numeric IDs stay explicit because their frozen schema does not bind numeric storage codes; enum order is not substituted for a frozen code. This removes an actual duplicate representation rather than moving source out of the count.

The second extraction uses one pure transition rule per existing command to own source-state/action/target/effects. The deciding function still checks project membership first, state second, stage authorization third, and then the command-specific checks in their original order. Block/unblock retain their dynamic origin; start retains developer/owner rather than pending-stage manager authorization. Public command and model types remain dataclasses with their current constructor signatures. Workflow proof resolution, D008 state then manager then baseline priority, freshness checks, CAS and audit boundaries remain in the application layer.

The third extraction replaces repeated trusted field projections and project/task ownership reads with a common implementation, keeping all calls in their original order. Only statically selected trusted field names may enter persistence construction. Readable operation bodies keep policy guards, query/lock choices and transaction boundaries visible. Expected first-pass net reduction is 150-250 lines including new helpers; further passes will be evaluated after real fixed-cloc results. The requested 600-700 reduction is an aspiration, not a measured result.

Validation: fixed cloc 2.10 with its supplied SHA; existing pure domain cases, SQLite-backed HTTP application cases including release priority and dependency behavior; new differential pure-domain cases against a git-show copy of the exact base. AST equality is claimed only for unchanged function bodies or mechanical projection expansion, never for the complete structural rewrite. Functional development tests do not establish independent acceptance, MySQL lock behavior, formal performance or release completion.
