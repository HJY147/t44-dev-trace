# Neutral functional environment provider

The independent operator owns all cases and business expectations. The coordinator reads only the explicit PUBLIC manifest/control protocol and PUBLIC nonce scope requests. No private suite, journal, log, key or private Git object is read. A source-bound native API/consumer and five disposable human sessions are supplied; projects and iterations are not pre-created.

An admitted functional grant names the precise source/native build/runtime, loopback HTTPS origin and resources, expiry and finite limits. A bounded provider watches only PUBLIC/handoff/*request.PUBLIC.json, verifies the active grant/freeze/runtime/source/resource/phase binding, request time, exact positive project IDs and scope, then creates a new service token for those real IDs via the frozen production administrative CLI. No future or wildcard scope is granted. The token is saved in a fresh private nonce directory, passed to the deployment-owned scheduler replacement controller, then delivered through the frozen PUBLIC OAEP sealer using stdin. Credentials never appear in argv or public output.

The scheduler is one active process. Each successful handoff replaces its prior exact project scope; earlier tokens remain scoped to their own projects for API use, but earlier projects are no longer periodically scanned. The provider records this limitation honestly. It does not infer case results from a provisioning success, retry a failed mutation, change business data, or inspect a case. A missing/failed scope handoff remains unproved in the independent result.

The provider stops at the grant deadline, accepts at most 40 unique scope requests, uses non-overwriting receipts and checks controller/tool hashes before execution. New process startup/shutdown is owned by deployment receipts and the existing independent watchdog. No shared MySQL daemon or old resources may be stopped. This provider is prepared while PUBLIC technical review is pending; it cannot run unless the final grant explicitly admits the reviewed freeze.
